# 像素 MG

把中文讲解文稿制作为可编辑的 HyperFrames 知识解释动画，表现机制、关系、比较与流程。

- [Skill 入口](SKILL.md)：输入、分镜、制作与交付。
- [安装与运行](DELIVERY.md)：Node.js 22+、锁定 HyperFrames 运行时及配套 Skill。
- [风格选择](references/style-contract.md)：默认青柠玻璃/白金黑纹理，另有朱砂活字剧场、工程图册与建筑剖面轴测。
- [Pixel2All 物件](references/object-library.md)：从本拍意图发现候选、看图比较，再按需导入与追溯。
- [内容驱动的变化](references/content-led-variation.md)：约70%延续现有风格，约30%按主题设计机制、空间与转场，质感贯穿全片。
- [支持和验证范围](references/release-scope.md)：工程、导出及艺术评审边界。

```text
用 xiangsu-mg 把这段中文讲解做成知识型 MG。
风格用青柠玻璃，先看代表性片段，再扩展整片。
```

当前安装源码版本见 SKILL 的 metadata。历史免费公开发行包：[preview.25](https://github.com/maverickgao8848/mav-mg/releases/download/v0.1.0-preview.25/mav-mg-0.1.0-preview.25.zip)。公开历史版本的内容以该版本为准。
