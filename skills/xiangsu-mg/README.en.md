# Xiangsu MG

Create editable HyperFrames educational motion graphics from Chinese narration, timed inputs and scene references.

- [Skill entry](SKILL.md): inputs, storyboard, production and delivery.
- [Installation](DELIVERY.md): Node.js 22+, pinned runtime and companion skills.
- [Style contract](references/style-contract.md): Glass Lime/Baijin defaults, Vermilion Theatre, Gable Reed and Architectural Section.
- [Object acquisition](references/object-library.md): intent-led candidate discovery, visual comparison, selected images and provenance.
- [Content-led variation](references/content-led-variation.md): retain roughly 70% familiar visual language and use roughly 30% for topic-specific mechanisms, space and handoffs, with consistent finish throughout.
- [Verified scope](references/release-scope.md): engineering, export and artistic review evidence.

The installed version is defined in SKILL metadata. [Historical free preview.25](https://github.com/maverickgao8848/mav-mg/releases/download/v0.1.0-preview.25/mav-mg-0.1.0-preview.25.zip) retains its original contents. Code and resources follow [LICENSE](LICENSE) and item-specific notices.
